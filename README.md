Rideguard is a DSA end-semester project that demonstrates taxi-trip safety monitoring with a browser dashboard. It uses simulated trip updates to show alerts for GPS interruptions, route deviations, speeding, device failures, and multiple anomalies.
## Requirements

- Python 3.10 or newer
- No additional Python packages required

## Run the project

Open a terminal in the project folder and run:

```powershell
python server.py
DSA concepts
- Weighted graph with Dijkstra and A* pathfinding
- FIFO queue and trip hash map
- Min-heap for GPS update deadlines
- Sliding windows and a set for anomaly monitoring
- Sorting sample safe locations by road distance
